# **Домашнее задание к работе 9**

### Условие задачи:
Написать программу для вывода геометрической фигуры (параллелограмм, вариант №18) с заданием символа, длины основания a и высоты h с клавиатуры.


## **1. Алгоритм и блок-схема**
1. Начало — запуск программы.
2. Блок данных — инициализация переменных `symv`, `a`, `h` и счетчиков.
3. Блок ввода — считывание параметров с клавиатуры `scanf`.
4. Внешний цикл l — отвечает за переход на новые строки до достижения высоты h.
5. Вложенный цикл w1 — печатает пробелы для смещения (с каждой новой строкой печатает на один пробел больше).
6. Вложенный цикл v1 — печатает подряд a штук выбранных символов.
7. Блок вывода \n — осуществляет перевод строки в конце цикла для формирования правильного контура фигуры.
8. Конец — завершение работы

## **2. Реализация программы**
```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>
int main() 
{   
    setlocale(LC_ALL, "RUS");
    char symv;
    int a, h;

    printf("введите символ : ");
    scanf(" %c", &symv); 

    printf("введите a: ");
    scanf("%d", &a);

    printf("введите  h: ");
    scanf("%d", &h);

    printf("\nфигура:\n");

    for (int l = 0; l < h; l++) {

        for (int w1 = 0; w1 <= l; w1++)
            printf(" ");

        for (int v1 = 1; v1 <= a && l <= h; v1++)
            printf("%c", symv);

        printf("\n");
    }
}

```
